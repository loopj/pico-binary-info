# Vendored headers

Verbatim copies from the Raspberry Pi Pico SDK `pico_binary_info` module, kept
under the same `pico/binary_info/` namespace they use upstream:

> https://github.com/raspberrypi/pico-sdk/tree/master/src/common/pico_binary_info/include/pico/binary_info

- `binary_info/defs.h` — binary-info section markers and the header layout
- `binary_info/structure.h` — record types, tags, and the `BINARY_INFO_ID_RP_*` ids
